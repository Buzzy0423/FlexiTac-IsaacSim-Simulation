更新：2026-09-15。目标：在本仓库搭建 Dexmate + FlexiTac 环境，为固定四相机布局的视觉／触觉序列研究提供数据。

## 已完成

- 创建独立 `dexmate_isaacsim` Conda 环境，Isaac Sim 5.1.0 与 CAD 转换依赖可用，`pip check` 通过。
- Dexmate Vega-1U 官方模型已本地快照；四根手指采用定制 26 mm 指体，仿真凸起减少 0.5 mm。
- 打印版相对原始 STL 减少 0.8 mm；仿真／打印文件分开维护。
- 用户提供的 Vention AS-JF-312098 v6 STEP 已完整转换；桌面、支架、脚垫、端盖均保留。
- 机器人处于桌子短边中央、朝向桌内。原点和暂定间距见工作区 JSON。
- 基础 PhysX 落体、RTX 渲染通过；官方桌面上的方块静止接触通过。
- **关闭机器人自碰撞的对照条件下**，夹爪 `0.4 → 0 → 0.4 rad` 开合及四路名义相机输出通过。
- 实际入口是 `tools/validate_dexmate_scene.py`；原 ALOHA 环境未切换为 Dexmate。

## 下次从这里继续

**优先定位自碰撞，不先扩大训练或采集。**

1. 对照失败运行 v8 与成功对照 v11 的接触对、关节状态；检查导入后碰撞近似与固定连接间的排除关系。
2. 做局部修正后重新开启自碰撞，验证空夹开合；保留两指与物体接触，不能用全局关闭代替修复。
3. 再建立最小“接触—保持—释放”用例，接入 FlexiTac 采样和响应。

成功标准：明确记录启用的碰撞范围；空夹关节稳定，夹持物体时有合理接触，释放后触觉消失。
现有 FlexiTac 数值是距离与刚度估算的触觉信号，不能直接等同真实接触力。
