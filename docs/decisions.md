# 已确认决策

确认日期：2026-09-15。当前实现进度见 [STATUS.md](STATUS.md)，本页只维护仍有效的配置约束。

## 手指与触觉表面

- 使用官方 Vega-1U `dexmate-urdf==0.8.4` 的 `dexs_gripper`，在本仓库维护定制副本。
- 用户 STL 是 TPU 指体，不是整个手指连杆；保留金属件、安装孔、关节原点、轴和 26 mm 宽度。
- **仿真凸起比最初 STL 低 0.5 mm；打印凸起比同一最初 STL 低 0.8 mm。** 两个减量不是累计值。
- 仿真凸起已经代表传感器及防滑垫的最终外表面，不再叠加一层垫片几何。
- 仿真几何零位中心截面间隙约 0.009 mm，目标是近似轻触；这不等于 PhysX 接触已经验证。
- 当前打印面比仿真低 0.3 mm。如果每侧再贴 1 mm 垫片，实物最终会比仿真多 0.7 mm/侧。
  这个厚度差已告知用户；沿用其确认的减量，不擅自重做打印件，也不引入复杂校准流程。

## 桌子与工作区

- 使用用户提供的 **VentionAssembly_312098_v6.STEP** 官方模型。
- 名义桌面 1530 × 1080 mm、高 790 mm；完整 CAD 外包络约 1564 × 1114 × 791 mm，保留真实比例。
- 机器人放在 **1080 mm 短边中央，面向桌内**。
- 世界原点是近端短边中心在地面的投影；+X 进入桌内，+Y 向机器人左侧，+Z 向上。
- 机器人基座位置暂为 `[-0.49, 0, 0.187] m`；这是初始摆放值，桌沿距离未实测。
- 桌子采用静态三角面碰撞保留槽与支架；统一灰色仅为暂用显示材质。

## 环境与数据路线

- 独立 Conda 环境 `dexmate_isaacsim`，对应本仓库的 Isaac Sim 5.1.0 路线。
- 首批观测是 **vision + tactile**，机器人状态和动作作为条件；force／torque 在量的定义明确后再接入。
- 固定头部左右双目和左右腕相机共四路，腕相机跟随手臂；首轮不随机化安装布局。
- 优先完成小规模接触／释放验证，再做同步序列记录与规模扩展。
- 原 FlexiTac 输出根据距离、刚度及限幅估算触觉标量，不直接读取 PhysX 接触力。
- 自碰撞关闭仅是诊断条件，不能作为夹持或两指接触已通过的依据。
