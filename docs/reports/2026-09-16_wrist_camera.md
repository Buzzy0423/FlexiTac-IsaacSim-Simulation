# 自装腕相机替换：离线几何评估

结论：用户提供的相机与支架可作为官方腕相机安装的替换候选，安装坐标及保留基座几何吻合。
这次完成真实网格效果图、交互开合预览和局部几何检查；未激活正式资产，未进行 Isaac Sim 动力学或光学验证。

## 来源与安装关系

两个源文件均在 `Isaacsim_tactile_env/assets/dexmate/meshes/custom/`，保持原样：

| 文件 | CAD 坐标 XYZ 外包络尺寸 / mm | 三角面 | 闭合网格 |
| --- | --- | --- | --- |
| `camera_in_mount_frame_mm.stl` | 42.183 × 34.127 × 124.000 | 1400 | 是 |
| `dexmate_c960_base_camera_mount_skate_ramp_full_base_coverage_left_dual_limit_2mm_w16mm_tangent_YZ24deg.stl` | 82.402 × 37.087 × 82.277 | 15998 | 是 |

二者使用官方 `gripper_base.glb` 烘焙节点后的 CAD 坐标系。新支架与旧支架的 9891 个顶点中，
7112 个在 0.01 mm 内有对应顶点；安装基座的 Y/Z 外包络极值吻合。
共同缩放 `0.001` 后，沿用底座 visual 的 `xyz="0 0 0" rpy="-1.5708 0 1.5708"`。
近似坐标映射为 `(x, y, z)_CAD → (-z, x, -y)_gripper_base`，不增加拟合平移。
相机在夹爪坐标的 X 向宽度为 124 mm；STL 中的倾角已体现在网格内，不再叠加文件名的 24°。

官方相机安装并非只在 `camera_link.glb` 内。预览还从 `gripper_base.glb` 中移除了两个独立连通组件：

- 旧主支架：CAD bounds `[-96.147, -18.903, -41.335] → [9.201, 49.566, 40.942] mm`。
- 相机处旧安装零件：`[-71.913, 3.947, -17.300] → [-50.563, 41.142, 16.900] mm`。

其余底座、腕部连接件和当前 TPU 指体保留。按连通组件和 bounds 识别，不用平面切割截掉其他硬件。
左右官方 camera joint 的局部 origin 一致；效果图以左夹爪为代表，尚未验证左右整臂全姿态。

## 检查范围与结果

| 检查 | 结果 |
| --- | --- |
| 开合范围 | 0–0.7854 rad，含两端共 17 个采样姿态 |
| 新支架至运动手指表面最小距离 | 40.500 mm |
| 新相机至运动手指表面最小距离 | 80.640 mm |
| 新相机至保留底座／腕部连接件最小表面距离 | 16.052 mm |
| 相机与支架最小表面距离 | 0 mm：存在接触，不能仅凭此判断穿透 |
| 相机／支架互相内部采样 | 包围盒内分别检查 747／1224 个顶点和面心，没有超过 0.01 mm 的内部样点 |
| 新支架至保留硬件最小表面距离 | 0 mm，安装接触区尚未做完整实体配合审计 |

距离使用 coal BVH 查询实际视觉三角面，内部采样使用闭合网格立体角及最近三角面距离。
这些结果不等于连续扫掠、完整布尔交集、螺丝配合、全臂避碰或 PhysX 自碰撞通过。
支架固定区存在预期安装接触；未据此声称整个装配无干涉。
