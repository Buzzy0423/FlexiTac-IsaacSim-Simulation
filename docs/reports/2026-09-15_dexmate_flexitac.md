# Dexmate 四指 FlexiTac 接入验证

日期：2026-09-15（本机太平洋时间）。实现对应 `pad_66x26_v3` 仿真指体。

## 实现

- 四片采样面沿各指凸起外法线外移 2.1 mm；12×32 点、2 mm 间距，采样中心跨度 22×62 mm。
- ALOHA 原有 Warp 内核抽出为共享模块，距离到触觉值的弹簧公式也共用。
- 原生 Isaac Sim 适配器每物理步跟随四指与目标位姿；目标几何缩放烘焙为米，避免距离尺度混淆。
- 明确查询桌板方块和两个固定测试块，排除机器人；不新增实体垫片或修改 URDF 碰撞。
- 输出 `(4,12,32)` 浮点网格及世界位置加标量的 `(1,1536,4)` 数组；验证记录逐帧网格。
- 参数／调用见[指南](../guides/tactile.md)。

## 验证条件与结果

Isaac Sim 5.1.0，RTX 4080 SUPER，开启机器人自碰撞及已确认的局部碰撞修正。
官方 Vention 桌、近端桌板、四路相机、当前 66×26 mm 指体均在场景中。

最终运行目录：`Isaacsim_tactile_env/output/dexmate_tactile_20260915_v3/`；退出码 0，报告 `passed`。
v1/v2 的接触响应检查通过，但沿用原 60 Hz 渲染循环，会每两个物理步才记录一次。
v3 将渲染与物理步长均设为 1/120 s，并通过相邻记录物理步号差为 1 的断言。
共 7 阶段，每阶段 240 步，以 120 Hz 记录 1,680 帧；仿真时间约 0.025～14.025 s。
阶段之间的预览可能推进未记录的仿真步，NPZ 中保留真实时间与全局步号，不当作无间断长序列。

| 检查 | 结果 |
| --- | --- |
| 三段自由开合 | 四指所有采样值均为 0 |
| 第一固定块闭合阶段 | 四指均在第 68 步首次出现输出（步号从 0 起） |
| 两个测试块横向位置的保持阶段 | 四指分别通过持续实际接触和非零触觉检查 |
| 释放末尾 20 步 | 四指输出均为 0 |
| 全序列 | 所有数值有限且位于 [0,1] |
| 桌板静止接触／四相机／开合驱动 | 全部通过 |

全序列每指峰值，顺序 L1、L2、R1、R2：**0.9461、0.8964、0.9460、0.8957**。
`tactile_peaks.png` 分别选择每指峰值帧，并非同一时刻的四片读数。
第二个测试块位置偏向第一指，第二指输出为零，符合其离开采样面的状态。

6 项单元检查通过：原 3 项碰撞检查，加上四片坐标／镜像／间距、真实 Warp 闭合网格距离及饱和、
共享公式与旧 ALOHA signed/unsigned/归一化组合的数值一致性。
网格测试确认米制压入 0.5、1、2 mm 对应输出 0.25、0.5、1。涉及的 Python 文件 Ruff 通过。

可提交摘要：[2026-09-15_dexmate_flexitac_summary.json](2026-09-15_dexmate_flexitac_summary.json)。
全量输出保留在本机并由 Git 忽略。

## 边界与下一步

这是固定测试块的接触／触觉验证，尚非自由物体抓取、并行训练环境或同步四相机数据采集器。
虚拟采样面处于实体外，触觉可先于实际碰撞出现；物理接触由独立 PhysX 冲量检查确认。
输出为距离响应，不是实测力／压力。完整 ALOHA Isaac Lab 环境未启动重跑，公式一致性由单元检查覆盖。
下一步是在此接口上加入可移动物体的夹持、保持和释放。
